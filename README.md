# Library Management System

A command-line Library Management System built with Python and SQLite.

## Features
- **User Authentication:** SHA-256 password hashing with student and admin roles (`src/auth.py`).
- **Catalog Management:** Add, list, and search books by title, author, or genre (`src/books.py`).
- **SQLite Storage:** Automatic database initialization and persistent local records (`src/database.py`).

## How to Run
Run `python3 main.py` in your terminal to launch the interactive menu.
